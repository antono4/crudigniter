# CRUDIgniter

> **Created by Antono** | 🇮🇩 Indonesia

A CodeIgniter 4 package that makes CRUD operations easy through API.

## 🚀 About

CRUDIgniter simplifies CRUD (Create, Read, Update, Delete) operations in CodeIgniter 4 applications through a clean REST API interface.

## ✨ Features

- 📝 Easy CRUD operations
- 🔌 RESTful API
- ⚡ Fast integration
- 🛡️ Secure by default

## 📦 Installation

```bash
composer require antono4/crudigniter
```
